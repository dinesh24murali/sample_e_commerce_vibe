# Task 16: Admin Frontend Project Setup

## Priority: High
## Status: Pending
## Subagent: @react-frontend-builder

## Description
Initialize the Admin panel React SPA with proper folder structure, routing, and Redux store setup.

## Requirements
- Create the project inside an `admin/` folder at the repo root
- Use React 18+ with functional components and hooks
- Set up Redux Toolkit for state management
- Install and configure Ant Design as the UI component library
- Set up React Router for navigation
- Set up project folder structure: `src/{components,pages,hooks,services,utils,context,types,assets,styles}/`
- Configure API base URL via environment variable
- Set up axios or fetch wrapper for API calls

## Design Patterns
- Container vs Presentational Components
- Redux Toolkit Slices
