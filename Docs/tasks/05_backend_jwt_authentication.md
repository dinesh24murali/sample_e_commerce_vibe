# Task 05: Backend JWT Authentication Setup

## Priority: High
## Status: Pending
## Subagent: @django-backend-builder

## Description
Set up JWT token-based authentication for admin APIs. Configure Django REST Framework with JWT authentication.

## Requirements
- Install and configure `djangorestframework-simplejwt`
- Create login endpoint that returns access/refresh tokens
- Create token refresh endpoint
- All admin API endpoints must require JWT authentication
- Write tests for authentication endpoints
- Add adequate logging
