# Task 32: Customer Frontend Cart Page

## Priority: High
## Status: Pending
## Subagent: @react-frontend-builder

## Description
Create the shopping cart page where customers can view and manage their cart items.

## Requirements
- Fetch and display cart items from backend API
- Show for each item: book name, image, price, quantity, subtotal
- Update quantity (increase/decrease)
- Remove item from cart
- Show cart total (with discount and tax calculations)
- "Proceed to Checkout" button
- Handle loading, error, and empty cart states
- Protected page (requires login)

## Design Patterns
- Container vs Presentational Components
- Redux Toolkit Slices (cart slice)
