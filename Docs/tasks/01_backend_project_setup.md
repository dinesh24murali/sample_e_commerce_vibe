# Task 01: Backend Django Project Setup

## Priority: High
## Status: Pending
## Subagent: @django-backend-builder

## Description
Initialize the Django project with proper folder structure and settings splitting pattern. Set up PostgreSQL database configuration, environment variable handling, and base settings (installed apps, middleware, CORS, etc.).

## Requirements
- Create the Django project inside a `backend/` folder at the repo root
- Use settings splitting pattern (base, development, production)
- Configure PostgreSQL as the database
- Set up CORS headers for frontend communication
- Add `.env` support for secrets/configuration
- Set up proper folder structure following Django best practices
- Add `requirements.txt` or `pyproject.toml` with initial dependencies

## Design Patterns
- Settings Splitting (base/dev/prod)
